# Hiruy Recipe Platform

Built while participating in the Hiruy Technology Full-Stack Summer Bootcamp.
React + Vite + Tailwind CSS v4 + ESLint.

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run lint     # run ESLint
npm run build    # production build into dist/
npm run preview  # serve the production build locally
```

## Images

Copy your recipe images into `public/images/`:

- `veggies soup.png`
- `Grilled chicken Sandwitch.png`
- `doro wat.png`

(Filenames are referenced in `src/data/recipes.js`.)
